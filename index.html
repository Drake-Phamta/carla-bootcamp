0.9Tự kiểm tra & hỏi chatbot

Rớt VPN khi đang build — mất gì, còn gì?

Nếu build chạy trong tmux: không mất gì, tmux a -t build là thấy tiếp. Nếu chạy trực tiếp trong SSH: process nhận SIGHUP và chết; build UE4/CARLA là incremental nên chạy lại sẽ tiếp từ phần chưa xong.

Khác nhau giữa ~/.bashrc và export trên terminal?

export chỉ sống trong phiên shell hiện tại; ghi vào ~/.bashrc thì mọi shell mới (kể cả tmux window mới) đều có.

C.3Synchronous mode — bắt buộc khi thu data

  • Async (mặc định): server chạy nhanh nhất có thể, client chậm thì mất frame; các sensor không cùng thời điểm; không tái lập được.
  • Sync: mỗi world.tick() tiến đúng fixed_delta_seconds; server chờ client. Mọi sensor trong 1 tick có cùng frame.
  • Quy tắc docs: trong sync luôn dùng time-step cố định; fixed_delta_seconds ≤ max_substep_delta_time × max_substeps (vật lý chia bước con, nên < 0.0167 s mỗi bước con).
  • Chỉ một client được gọi tick(). Nếu Autoware interface đang tick thì script của bạn chỉ đọc (world.wait_for_tick()).
  • Traffic Manager cũng phải sync: tm.set_synchronous_mode(True).
